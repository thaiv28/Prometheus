- `scripts/research/audit_snapshots.py` is standalone snapshot research, separate from the DB build and site: `uv run python scripts/research/audit_snapshots.py` reads raw OE CSVs, audits 10/15/20-minute game completeness and champion/player identity coverage, and writes `docs/research/snapshot_report.md` plus gitignored `data/snapshot_audit/{coverage,metrics,predictions,league_scores,calibration_bins}.csv` and `manifest.json` (input SHA-256 hashes and fitted parameters). One row per game, blue-minus-red gaps, calendar year from timestamp, games lasting beyond each minute. All four models (total gold; gold+kills; lane stats without XP; AURA's 30 lane features) share the complete AURA cohort in major leagues and Worlds/MSI/EWC/FST. Each annual fold fits scaler/logistic regression on the prior three years excluding the calibration year, calibrates on the immediately preceding year, and scores the test year. Paired log-loss intervals resample league/day clusters (approximate series grouping). No imputation, final-game stats, database writes, forecast-weight refits, or market fetching. The 2026 holdout was scored with fixed settings; repeated runs reproduced its scores. Live feature availability remains a collection assumption.
- `tests/test_audit_snapshots.py`: synthetic raw-data tests for calendar-vs-season years, directly computed lane gaps, missing XP versus usable gold, games ending before a snapshot, malformed roles/results/metadata, invalid numeric values, missing identities, duplicate games across CSVs, and invariance of trained/scaled/calibrated parameters to future feature/outcome changes.

## Broadcast extraction pilot outside Prometheus

The separate `lol-live` repository (next to this one) owns bounded video acquisition/frame sampling and fixed-profile numeric OCR. Its `scripts/sample_vod.py` downloads explicit public YouTube sections only with --fetch, caps each section/batch, disables request retries, preserves success/failure manifests and hashes, uses bundled FFmpeg and 1 Hz frames. `scripts/read_scoreboard.py` requires the inspected 1920×1080 LCS layout and Tesseract, emits strict gold/clock candidates with nulls for malformed values, and always marks live_state_verified=false. Numeric parsing does not establish teams, game, replay context, confidence or receipt timing; pre-show gameplay can pass. Six local samples/72 frames are a feasibility dataset only. A subsequent YouTube sign-in/bot check stopped acquisition. See lol-live/README.md for checked commands and limits. No live model/market integration or historical-corpus modification.
