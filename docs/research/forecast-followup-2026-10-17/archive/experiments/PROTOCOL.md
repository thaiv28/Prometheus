# Experiment protocol frozen before outcome evaluation
Baseline source revision: ac5745ca1982d7347d7caee2f98f70f7f1832c53.
Research code is outside the repository; no production changes or merge.
Raw OE mirrors: hashes and source revisions in mirror-manifest.json. These are a reconstructed corpus, not verified identical to deployed data.
Development chronology: training through 2021; selection 2022–2023; final retrospective evaluation 2024 onward. The 2024 onward period has previously been viewed in other repository research; this is no prospective confirmation. Never tune against its outcomes.
Primary pre-match features: known prior-day team state; no current champions or actual starters. A separate post-draft test explicitly admits current champions. All dynamic feature updates wait until next UTC day; models fit only earlier years.
Baseline controls: packaged production coefficients; an earlier-only fitted same-architecture control. Regional calibration retains packaged earlier-event snapshots; prior selection of current Elo heuristics is retrospective.
Experiments: (1) no residual vs stable residual vs fixed roster reset vs two-regime Bayesian grid filter; (2) earlier-available champion-role win-rate levels/shifts, pre-draft and post-draft kept separate, one-day and 14-day publication lag sensitivity, missing-rate coverage reported, source provenance qualified; (3) within/cross-league mover bridge counts followed by a compact performance translation only when identifiable; (4) linear lagged style differences vs antisymmetric style interactions; (5) role-redundancy/comfort-value screen vs entropy and experience before any full draft simulator; (6) Bernoulli score equivalence control and joint residual observation prototype; (7) roster identification screen and hierarchical sparse player/pair/trio residual models only on estimable cohorts.
Primary score: paired map log loss; series/team-pair-day clusters, international event sensitivity. Report Brier and calibration. Domestic majors/minors and international major-major/major-minor/minor-minor, entry vs later, distinct where possible. Small or absent slices are not forced into a significance conclusion.
Keep test settings frozen after scoring. Record all attempted variants, failures, timing, and computational/availability limitations. Candidate rejection or feasibility failure is a result; it is not a completed full-scale model test.
